# Security Policy

## Supported Versions

The deployed mainnet program is the currently supported version.

## Reporting a Vulnerability

Please do not disclose exploitable issues in a public GitHub issue.

Use the repository security policy page if private vulnerability reporting is
available:

https://github.com/iceypump/staked/security/policy

If private reporting is not available, contact the project on X:

https://x.com/iceyypump

Include the affected program ID, a concise impact summary, reproduction steps,
and any transaction signatures or accounts needed to verify the issue.
